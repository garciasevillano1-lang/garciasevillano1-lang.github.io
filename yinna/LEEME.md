# Mis finanzas

App de yinna marcela sevillano gutierrez. Id interno: `mis-finanzas-a3aca` (no lo cambies: de él dependen los datos guardados en el celular).

## Publicar (GitHub Pages)
1. Crea un repositorio nuevo y público en GitHub (ej. `mis-finanzas`).
2. Sube TODOS los archivos de esta carpeta (index.html, manifest.json, sw.js, icons/, img/).
3. Settings → Pages → Branch: main, carpeta / (root) → Save.
4. En 1–2 minutos queda en https://TU-USUARIO.github.io/mis-finanzas/

## Instalar
- Android (Chrome): abre el enlace → aviso "Instalar app" o menú ⋮ → Instalar app.
- iPhone (Safari): Compartir → Agregar a inicio.

## Actualizar sin borrar sus datos
Vuelve a generar con `--id mis-finanzas-a3aca` y sube los archivos al MISMO repositorio.
